# Racket Tuner

Rechner für das Tuning von Tennisrackets mit Bleiband: Du gibst Gewicht, Balance, Schwunggewicht und Twistweight ein. Die App berechnet, wo am Racket wie viel Gewicht nötig ist, um deine Zielwerte zu erreichen.

**App öffnen:** https://juicyfruitaccount.github.io/Racket-tuner/

Formeln: Steiner'scher Satz mit Schwungachse 10 cm vom Griffende (Quelle: Tennis Warehouse University).
